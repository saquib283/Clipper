# Custom Meme & Subtle SFX Drop-In Folder

Drop any `.mp3`, `.wav`, `.ogg`, `.m4a`, or `.flac` sound effect into this folder.
`youtube-clipper` automatically discovers all files here during `probe` (in `analysis.json -> signals.available_sfx`)
and mixes them cleanly with automatic limiting and gain staging so loud downloads never blow out audio.

## How Custom Overrides Work
- Filename stem (lowercase) becomes the SFX name in `clips_plan.json` (e.g., `brother-eww.mp3` -> `"sfx": "brother-eww"`).
- Dropping a file with the same name as a built-in sound (e.g., `vine-boom.mp3` or `metal-pipe.mp3`) automatically overrides the built-in synthesized version!
