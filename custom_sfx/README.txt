# Custom Viral Meme & Subtle SFX Soundboard (`custom_sfx/`)

Any `.mp3`, `.wav`, `.ogg`, `.m4a`, or `.flac` file in this folder is automatically discovered by `youtube-clipper`
(from any workspace!) via `signals.available_sfx` in `analysis.json`. Files here override same-named built-in starter WAVs
and are automatically gain-staged + limited so loud downloads never blast over dialogue.
